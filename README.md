## Сравнительный анализ методов выпуклой оптимизации (TV-Denoising)

Этот проект представляет собой исследование и сравнение методов выпуклой оптимизации (Сглаженный GD, ISTA, FISTA) на примере задачи восстановления изображений с использованием регуляризации полной вариации (Total Variation Denoising).

Скрипт `main.py` выполняет полный цикл исследования:
1.  Находит оптимальный параметр регуляризации `lambda`.
2.  Сравнивает три метода по скорости сходимости и качеству результата.
3.  Сохраняет все графики и изображения в текущую папку.

### Как запустить

1.  **Установите зависимости:**
    Выполните команду для установки необходимой библиотеки:
    ```bash
    pip install numpy matplotlib scikit-image
    ```

2.  **Запустите скрипт:**
    ```bash
    python main.py
    ```

После выполнения скрипта (1-2 минуты) в папке появятся `.png` файлы с результатами исследования.
